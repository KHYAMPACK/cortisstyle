# 11 — Cortisstyle design inspiration (not boutiques)

**Purpose:** External reference sites for the **main Cortisstyle product** — international lookbook (`/`), wardrobe, discovery, and AI-assisted shopping UX.  
**Not for** Phase 1 boutique storefronts — those use [10-boutique-design-inspiration.md](./10-boutique-design-inspiration.md).

## How agents should use this list

- **Yes — agents should refer to these sites** when designing Cortisstyle home, look discovery, wardrobe, or AI browse/search experiences.
- Open or fetch the live URL; prefer each site’s **What we like** notes.
- Extract **principles** (onboarding, conversational search, composition). Do **not** copy assets, branding, or build a pixel clone.
- Do **not** apply these references to `/tr/[slug]` boutique themes unless the product owner explicitly says so.

## Reference sites

### Brunello Cucinelli — AI Online Boutique

- **URL:** https://shop.brunellocucinelli.com/en-gb/ai
- **Scope:** Cortisstyle only (lookbook / AI discovery UX) — **not** boutique storefronts.
- **Focus:** first-run experience + conversational “type what you want” shop flow.
- **What we like (study this):**
  - **Info cards at the start** — short onboarding that explains the best way to use the experience (e.g. “Browse ideas”, “Submit a request”) with a preview image, serif title, quiet body copy, step dots, Skip / Continue
  - **Whole AI browse experience** — idea carousel, calm luxury atmosphere, brand-led hero line (“Where ideas become endless possibilities”)
  - **Typing what you want** — persistent natural-language input (pill search/chat bar) as the primary way to discover looks and products, not only menu navigation
  - Tone: minimal, high-end, uncluttered; photography + serif display + soft UI chrome

### Dolce & Gabbana — Gift Finder Quiz

- **URL:** https://beautytools.dolcegabbana.com/en-tr/gift-finder/quiz
- **Scope:** Cortisstyle only (guided discovery / quiz UX) — **not** boutique storefronts.
- **Focus:** quiz-style gift finder that recommends products from a few preference questions.
- **What we like (study this):**
  - **Guided quiz flow** — short, branded steps that turn vague intent (“I need a gift / look”) into concrete recommendations
  - **Apply to clothing** — same pattern maps well to Cortisstyle: occasion, vibe, fit preference, recipient, or wardrobe gap → curated looks / outfits (not beauty SKUs)
  - Study progression, question UI, and how results are presented — principles only; do not copy D&G branding or beauty content

## Adding sites

For each new site, note **Cortisstyle (not boutiques)**, **URL**, **Focus**, and **What we like** from the product owner.
