# TikTok Content Ruleset — Cortisstyle

Guidelines for the person managing the Cortisstyle TikTok account. Goal: **drive US shoppers to specific looks on cortisstyle.com** and earn affiliate commission — not generic brand awareness only.

**Audience:** ~44% USA (primary). Rest is mixed international — still post in English, prioritize US-shoppable looks.

**Site:** https://www.cortisstyle.com

---

## Roles

| Person | Responsibility |
| ------ | -------------- |
| **TikTok manager (you)** | Film/edit/post, captions, bio link, pinned comments, on-screen CTAs, trends, posting schedule |
| **Cortisstyle / Mert** | Live looks on site, shop links working, new looks published, affiliate tags, fixes broken links, approves which look to push |

**Rule:** Do not post a “shop this look” video until Mert confirms the look is **live + links work** on the site.

---

## Golden rule

**One post = one look = one link.**

Every shoppable post must send people to a **specific look URL**, not just “cortisstyle.com” at the end.

**Good pinned comment:**
```
Full look + shop links → cortisstyle.com/?look=look-04&utm_source=tiktok
```

**Bad:**
```
cortisstyle.com
```

---

## Posting cadence

| Frequency | Content |
| --------- | ------- |
| **3× / week minimum** | Look-specific posts (shop this fit, GRWM, piece breakdown) |
| **1–2× / week** | Mood/aesthetic/teaser (can still link to a look if natural) |
| **Max 1–2× / day** | Do not spam — quality over volume |

**Best times to test:** US evenings (EST) — check TikTok analytics after 2 weeks and adjust.

---

## Post types (priority order)

### 1. Shop this look (required — most of your posts)

- Show the full outfit
- Name 2–3 hero pieces verbally or on screen
- Screen record: open site → tap look → show shop links (3–5 sec)
- Pinned comment with look deep link

**Formats:** GRWM, “every piece in this fit,” outfit check, transition into look.

### 2. Trend + our aesthetic

- Use trending audio/format
- Outfit must match Cortisstyle lookbook vibe
- Still end with look link if shoppable

### 3. Teaser / editorial

- No shop CTA required
- Use for brand mood, BTS, collage aesthetic
- Optional soft CTA: “more on the site”

**Do not:** Post only generic montages with no link — that builds views but not money.

## Legal (TikTok — required)

US FTC expects disclosure **where you promote shopping**, not only on the website.

| When | What to do |
| ---- | ---------- |
| Post drives to site to **shop** | Caption or on-video: `affiliate links` / `links may earn commission` |
| Brand **paid** you for the post | Use `#ad` or `paid partnership` |
| Pure aesthetic, no shop mention | No disclosure needed |

**Safe default for shop posts:** add to caption:
```
Links may earn commission · affiliate
```

## What to post vs avoid

### Do

- Film in good light; show full outfit head-to-toe when possible
- Use look titles / vibe words from the site (“SS26 Look 04”, editorial tone)
- Remake top performers every 4–6 weeks with “updated links on site”
- Reply to comments asking “where’s the jacket?” with look URL
- Keep aesthetic consistent: editorial, curated, not chaotic fast-fashion energy
- Tag Cortisstyle account if separate from personal (if applicable)

### Don't

- Post a look before links are live on site
- Only say “link in bio” with no pinned comment URL
- Promise exact Depop/vintage pieces that may be sold (say “similar links on site”)
- Delete pinned comment with shop link
- Use misleading `#ad` when it’s only affiliate (use “affiliate links” instead)
- Post more than 2 shoppable videos for the same look in one week (audience fatigue)
- Change bio link to random pages without telling Mert

## Pre-post checklist (send to Mert if unsure)

Before posting a **new** look for the first time:

1. What is the look ID? (e.g. `look-04`)
2. Are all shop links working on mobile?
3. Is this look US-friendly (shipping / retailers)?
4. Any piece sold out? (Mert should swap link first)

**Slack/DM template to Mert:**
```
Posting tomorrow — Look 04 (Concrete Romance)
Pinned: cortisstyle.com/?look=look-04&utm_source=tiktok
OK to go?
```

## When something breaks

| Problem | Action |
| ------- | ------ |
| Link in bio wrong | Fix immediately; comment on recent posts with correct link |
| Site down | Pause shoppable posts; aesthetic-only OK |
| Piece sold out | Tell Mert before next post; don’t pin broken look |
| Video under 1K views | Normal — don’t delete; improve hook next time |
| Video 100K+ | Tell Mert same day — remake with strong CTA while hot |

## Success metrics (3 months)

| Signal | Good sign |
| ------ | --------- |
| Pinned comment clicks | People asking “where’s the link” less often |
| Profile visits | Up week over week |
| Site look opens | Matches posts pushed |
| First affiliate sale | Milestone — tell Mert immediately |

Views alone are not success. **Look opens + shop clicks** are.
