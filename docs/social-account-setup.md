# Social Account Setup — TikTok & Instagram (@cortisstyle)

Step-by-step instructions for launching **@cortisstyle** from zero on TikTok and Instagram. No creative assets included — copy, settings, and structure only.

**Site:** https://www.cortisstyle.com  
**Primary market:** United States (~44% of audience)  
**Monetization:** Affiliate / shop links on site  
**Posting model:** You own accounts, post, and link. Friend may supply raw clips early — she does not manage profiles.

---

## Before you open the apps

Checklist:

- [ ] At least **3 looks** live on site with working shop links (confirm on your phone)
- [ ] Know your **hero look ID** for week 1 (e.g. `look-04`)
- [ ] **Profile photo** ready: square, 1:1, works at tiny size (logo or strong outfit flat lay)
- [ ] **Email** you control on both accounts (not your friend’s)
- [ ] **Phone number** you control for 2FA
- [ ] Decide bio link: **direct deep link** (simplest) or **Linktree/Beacons** (if you want multiple links later)

---

## Part 1 — TikTok (@cortisstyle)

### 1.1 Create / claim account

1. Install TikTok → Sign up with **your email** or phone (must be yours).
2. Username: **`cortisstyle`** (if taken, use `cortisstyle.com` or `cortisstyle_` temporarily — correct spelling matters).
3. Do **not** let anyone else hold the login.

### 1.2 Switch to Business or Creator account

**Path:** Profile → ☰ menu → **Settings and privacy** → **Account** → **Switch to Business Account** (or Creator)

| Choose | Why |
| ------ | --- |
| **Business** or **Creator** | Analytics, bio link, commercial tools |
| Category | **Shopping & retail** or **Art** / **Fashion** (pick closest) |

Business is fine for affiliate fashion lookbooks.

### 1.3 Profile — every field

**Profile photo**

- Upload **Cortisstyle logo** or minimal editorial image
- Must read at ~50×50 px — avoid busy detail
- Same image as Instagram for consistency

**Display name** (30 characters max)

```
Cortisstyle
```

Optional subtitle style (if TikTok allows second line in your region):

```
SS26 Lookbook
```

**Username**

```
@cortisstyle
```

**Bio** (80 characters on TikTok — keep tight)

**Option A — shop-forward (recommended):**

```
SS26 lookbook · shop the fit
curated outfits ↓
links may earn commission
```

**Option B — shorter:**

```
Editorial SS26 looks
Full fits + shop links ↓
```

**Bio link**

TikTok allows **one clickable link** on Business/Creator accounts.

**Week 1 (recommended — highest conversion):**

```
https://www.cortisstyle.com/?look=look-04&utm_source=tiktok&utm_medium=bio
```

Replace `look-04` with your current hero look. **Update this when your pinned video changes.**

**Alternative — lookbook section:**

```
https://www.cortisstyle.com/?utm_source=tiktok&utm_medium=bio#lookbook-collection
```

**Do not** leave bio link empty after first post.

### 1.4 TikTok settings (go through each)

**Settings and privacy → Account**

| Setting | Recommendation |
| ------- | -------------- |
| Phone / email | Yours only; enable 2-step verification |
| Password | Strong, unique |
| Manage account → Delete | Know where it is; don’t touch |

**Settings and privacy → Privacy**

| Setting | Recommendation |
| ------- | -------------- |
| Private account | **Off** (public — you need FYP) |
| Suggest account to others | **On** |
| Allow downloads | **Off** (optional — reduces reposts without credit) |
| Activity status | Your preference (Off is fine) |

**Settings and privacy → Content & Display**

| Setting | Recommendation |
| ------- | -------------- |
| Language | **English** |
| Region / content preferences | US-relevant content will follow your posts |

**Settings and privacy → Creator tools** (or Business tools)

| Tool | Action |
| ---- | ------ |
| **Analytics** | Turn on — check weekly |
| **Creator Center** | Bookmark on desktop |

**Settings and privacy → Ads** (if visible)

- No action needed unless running ads later

**Settings and privacy → Commercial content** (important for affiliate)

| Setting | Recommendation |
| ------- | -------------- |
| **Disclose commercial content** | Turn **On** |
| When posting shoppable content | Toggle **“Your video promotes goods or services”** (or equivalent) per TikTok’s flow |

This supports FTC-style transparency for affiliate posts.

**Settings and privacy → Interactions**

| Setting | Recommendation |
| ------- | -------------- |
| Comments | **Everyone** (reply fast to “where’s the link?”) |
| Filter keywords | Optional: block spam words |
| Duet | **Everyone** or **Friends** (Everyone helps trends) |
| Stitch | **Everyone** |
| Mention | **Everyone** |

**Settings and privacy → Notifications**

- Enable: **Comments**, **New followers**, **Analytics** (weekly digest if offered)
- Disable noise you won’t read

### 1.5 First content actions (TikTok)

1. **Post video #1** — your strongest look (don’t post blank profile long).
2. **Pin video #1** to profile (long-press → Pin).
3. **Pinned comment** on every shoppable video:

   ```
   Full look + shop links → https://www.cortisstyle.com/?look=look-XX&utm_source=tiktok
   ```

4. **Caption template:**

   ```
   SS26 Look 04 — full breakdown + shop links on site (pinned)
   Links may earn commission · affiliate
   #fashion #outfitinspo #lookbook #ss26 #cortisstyle
   ```

5. Hashtags: **3–5 max** — don’t spam 30 tags.

### 1.6 TikTok posting defaults (your SOP)

Every shoppable post:

- [ ] Look confirmed live on site
- [ ] Pinned comment with look URL + `utm_source=tiktok`
- [ ] On-screen text last 2 sec: `LINK IN BIO` or `FULL LOOK ON SITE`
- [ ] Commercial/affiliate disclosure (caption or toggle)
- [ ] Bio link matches pinned look (update when hero post changes)

**Cadence:** 1 post/day while you have 20-outfit bank, minimum 3 shoppable posts/week long-term.

### 1.7 TikTok analytics — what to check weekly

Creator tools → Analytics:

- **Video views** (7 days)
- **Profile views**
- **Follower count** (secondary metric)
- **Traffic source:** For You vs Follow vs Search
- **Audience territories** — watch US % stay healthy

Screenshot top post + send to yourself in Notes — track which **look IDs** perform.

**Meta Business Suite (optional, later)**

- Not required day 1

### 2.5 Instagram content structure

**Grid strategy (simple):**

- **Reels = main format** (repurpose TikTok — export without watermark or re-edit)
- Feed posts: **optional** — 1 carousel/week max (outfit flat lay + “link in bio”)
- **Stories:** repost Reels, “new look live”, link sticker when you have 10k+ followers OR use link in bio CTA until then

**Highlights (optional, week 2+):**

| Highlight name | Cover | Content |
| -------------- | ----- | ------- |
| SS26 | Logo or “SS26” text | Best 3–5 looks |
| SHOP | Bag icon or text | Story clips showing site |
| ABOUT | “?” | 1 story: what Cortisstyle is |

Skip highlights until you have story content — not day-1 critical.

### 2.6 Instagram Reels posting SOP

When reposting from TikTok:

1. Export TikTok **without watermark** (edit in CapCut/draft before posting to TikTok, or screen record — watermark-free export is cleaner)
2. Post as Reel
3. Caption — same as TikTok but change UTMs in any written URL to `utm_source=instagram`
4. Cover frame: pick clearest outfit frame
5. Share to Feed: **Yes** (helps grid look alive)
6. Alt text (optional): `"SS26 Look 04 — Cortisstyle editorial outfit lookbook"`

**Cadence:** 2–3 Reels/week (repurpose best TikToks) — don’t burn out duplicating daily unless easy.

### 2.7 Instagram analytics

Professional dashboard → Insights:

- **Reach** (7 days)
- **Reels plays**
- **Profile visits**
- **Link taps** (if shown)
- **Top locations** — US should lead over time

Check **weekly**, same day as TikTok review.

## Part 4 — Bio link rotation schedule

When you post a new **hero look**, update **both** bios the same day:

| Week | Hero look | Bio link |
| ---- | --------- | -------- |
| 1 | look-04 | `.../?look=look-04&utm_source=tiktok&utm_medium=bio` (IG: instagram) |
| 2 | look-05 | Update both bios |
| 3 | look-06 | Update both bios |

**Pinned TikTok** should match bio look that week.

Instagram has no “pin” — bio link is the main CTA.

| --------- | ------- |

| Instagram bio | `utm_source=instagram&utm_medium=bio` |
| Instagram caption URL | `utm_source=instagram&utm_medium=caption` |


## Part 8 — What NOT to do

- Don’t leave bio empty after posting
- Don’t post “cortisstyle.com” without look ID on shoppable content
- Don’t give friend posting access “just for convenience”
- Don’t use `#ad` for affiliate-only posts (use “affiliate links” / commercial toggle)
- Don’t mismatch handles (`cortisstyl` vs `cortisstyle`)
- Don’t obsess over follower count week 1 — track **profile visits** and **look opens** on site
- Don’t post looks before shop links work on mobile
